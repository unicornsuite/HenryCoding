Einstellungen

Die Spracherkennung läuft über Apple (Safari) bzw. Google (Chrome). Das Mikrofon wird erst beim Tippen auf den Mikrofon-Knopf angefragt.
Online-Stimmen klingen natürlicher; der gesprochene Text geht dann an Google bzw. Microsoft. Auf dem iPhone gibt es nur Gerätestimmen.
Bessere Stimme auf dem iPhone: Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch → eine „Erweitert“- oder „Premium“-Stimme laden (z. B. Anna, Petra). Danach die Seite neu laden.
Eine natürliche Stimme, die komplett im Browser rechnet, auch auf iPhone und iPad. Einmal herunterladen, hier importieren, fertig: Die Dateien bleiben in diesem Browser gespeichert und werden nirgendwohin geschickt.
So geht's:
1. Zwei Dateien laden, Empfehlung Deutsch: de_DE-thorsten-low.onnx (ca. 20 MB) und de_DE-thorsten-low.onnx.json. Weitere Stimmen: Deutsch, alle Sprachen (Qualität „low“ ist auf dem Handy am flüssigsten, „medium“ klingt besser, ca. 60 MB).
2. Beide Dateien unten auswählen (auf dem iPhone aus „Dateien“ › „Downloads“).
